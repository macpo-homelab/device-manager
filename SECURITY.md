# Sicherheit

Der Device Manager verwaltet Zugangsdaten (Geräte-Passwörter, OPNsense-API-Schlüssel, WLAN-Passwort) und private
Schlüssel von Zertifikaten. Sicherheitslücken bitte **nicht** als öffentliches Issue melden, sondern vertraulich über
**Security → Report a vulnerability** in diesem Repository.

Bitte angeben:

- betroffene Version (siehe `CHANGELOG.md` oder Info der Home-Assistant-App),
- Beschreibung und Auswirkung der Lücke,
- Schritte zum Nachvollziehen.

Ich melde mich in der Regel innerhalb einer Woche. Unterstützt wird jeweils nur die neueste Version.

Die Sicherheitsannahmen des Projekts stehen in [docs/04-security-review.md](docs/04-security-review.md).
